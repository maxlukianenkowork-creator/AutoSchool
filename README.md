# AutoSchool Android MVP

Готовый MVP Android-приложения «Управление уроками вождения» по спецификации.

## Что реализовано
- Локальная авторизация (MVP-заглушка для входа).
- Учёт учеников: добавление и список.
- Учёт занятий: создание занятия и история.
- Учёт оплат: добавление платежей и список.
- Базовый отчёт: ученики, занятия, общий доход.
- Оффлайн-режим через Room (данные хранятся локально).
- Интерфейс на русском языке.

## Стек
- Kotlin + Jetpack Compose
- Room Database
- Material 3
- Min SDK 26 (Android 8.0)

## Сборка APK
1. Установить Android SDK и JDK 17.
2. Сгенерировать Gradle Wrapper (если отсутствует):
   `gradle wrapper`
3. Собрать debug APK:
   `./gradlew assembleDebug`
4. APK будет в:
   `app/build/outputs/apk/debug/app-debug.apk`

## Ограничения текущего MVP
- Нет backend-синхронизации и SMS-подтверждения (вход локальный).
- Нет админ-панели.
- Нет push-уведомлений и drag-and-drop календаря.

Это можно добавить на следующем этапе как расширение текущей архитектуры.
