# Техническая спецификация
## Android-приложение «Управление уроками вождения»

## 1. Общая информация
- **Платформа:** Android
- **Минимальная версия ОС:** Android 8.0 (API 26)
- **Тип приложения:** Нативное Android-приложение
- **Язык интерфейса:** Русский
- **Техническая часть (backend и документация):** English

### 1.1. Цель проекта
Разработать мобильное приложение для инструкторов автошколы, позволяющее:
- вести расписание занятий;
- фиксировать проведённые уроки;
- отслеживать прогресс учеников;
- учитывать оплаты;
- формировать отчёты.

## 2. Пользовательские роли
### 2.1. Инструктор
- Управление расписанием
- Учёт занятий
- Отслеживание прогресса учеников
- Учёт оплат
- Формирование отчётов

### 2.2. Администратор (опционально)
- Просмотр всех инструкторов
- Управление учениками
- Контроль оплат
- Экспорт отчётов

## 3. Функциональные требования
### 3.1. Авторизация
- Вход по номеру телефона + SMS-код
- Вход по логину и паролю
- Восстановление пароля
- Разграничение прав по ролям (Инструктор / Администратор)

### 3.2. Управление учениками
**Карточка ученика:**
- ФИО
- Номер телефона
- Дата начала обучения
- Категория прав (B, C и т.д.)
- Предоплаченные часы (общее количество)
- Стоимость часа
- Примечания

**Функции:**
- Добавление ученика
- Редактирование данных
- Удаление
- Поиск
- Фильтрация (Активные / Завершившие)

### 3.3. Управление занятиями
**Создание занятия:**
- Дата
- Время начала и окончания
- Длительность (автоматический расчёт)
- Тип занятия (Город / Площадка / Подготовка к экзамену)
- Темы занятия
- Оценка прогресса ученика
- Комментарий инструктора

**Функции:**
- Автоматическое списание часов из баланса ученика
- Отметка занятия как оплаченного
- Отмена занятия
- История занятий по каждому ученику

### 3.4. Финансовый учёт
**Фиксация оплаты:**
- Дата платежа
- Сумма
- Способ оплаты (Наличные / Банковский перевод)

**Автоматические расчёты:**
- Оплаченные часы
- Отработанные часы
- Остаток часов
- Общий доход инструктора

**Отчётность:**
- Финансовые отчёты за выбранный период

### 3.5. Расписание
- Календарный вид (День / Неделя)
- Создание занятия прямо из календаря
- Перенос занятий drag-and-drop
- Напоминания о ближайших занятиях
- Push-уведомления

### 3.6. Отчётность
**Отчёты инструктора:**
- Количество занятий за период
- Общий доход
- Количество активных учеников

**Отчёты администратора:**
- Отчёт по каждому инструктору
- Общая выручка автошколы
- Экспорт в Excel / PDF

## 4. Нефункциональные требования
### 4.1. Производительность
- Время загрузки экранов: ≤ 2 секунд
- Стабильная работа при 1000+ учениках

### 4.2. Безопасность
- Шифрование локального хранилища
- HTTPS для передачи данных
- Разграничение прав доступа
- Регулярное резервное копирование данных

### 4.3. Оффлайн-режим
- Работа без подключения к интернету
- Автоматическая синхронизация при восстановлении сети

## 5. Интеграции
- SMS-провайдер
- Push-уведомления (Firebase)
- Экспорт в Google Drive (опционально)

## 6. UI/UX требования
- Простой и интуитивный интерфейс
- Крупные кнопки для быстрого доступа
- Поддержка светлой и тёмной тем
- Чистая структура навигации
- Полностью русскоязычный интерфейс

## 7. Архитектура
- Клиент-серверная архитектура
- REST API
- База данных: PostgreSQL или Firebase
- Локальное хранилище: Room Database

## 8. Этапы разработки
1. Аналитика и планирование (1–2 недели)
2. UI/UX-дизайн (2 недели)
3. Разработка MVP (4–6 недель)
4. Тестирование (2 недели)
5. Публикация в Google Play
6. Поддержка и развитие

## 9. Объём MVP
### Включено в MVP
- Авторизация
- Управление учениками
- Учёт занятий
- Расчёт баланса часов
- Базовая отчётность

### Исключено из MVP
- Панель администратора
- Онлайн-платежи
- Продвинутые интеграции

## 10. Дальнейшее развитие
- Отдельное приложение для учеников
- Интеграция онлайн-оплат
- Автоматические SMS-напоминания
